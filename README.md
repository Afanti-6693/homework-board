# 小学生电子记作业本（可分享到 QQ · 公开共享本）

一个给小学生用的「电子记作业本 / 每日任务」网页：家长或老师做好清单 → 分享链接发到 QQ → 孩子点开就能看到当天任务并逐项勾选完成。**不用密码，谁拿到链接谁就能打开，家人和孩子看到的是同一本，约 20 秒同步。**

## 功能
- **作业清单**：可粘贴微信群作业，自动按换行/序号/标点拆成多条；科目、时间自动归类
- **课堂笔记**（语文/数学/英语）：支持文字 + 图片，图片可上传或粘贴微信图片
- **老师通知 / 家长任务**两类标签：记录提醒、明日要带的东西、家长需帮忙的事
- **图片识别作业**：直接上传/粘贴黑板、白板、微信群作业截图，浏览器本地 OCR 识别成文字（**无需后端，免费平台也能跑**）
- **公开共享本（无密码）**：作业存在云端，链接即钥匙（`?b=随机ID`），家人父子共用同一本、实时同步
- **17:30 自动提醒**：页面常开到点弹提醒 + 一键分享到 QQ

## 本地运行（完全脱离云端，数据存自己电脑）
```bash
node server.js          # 默认 http://localhost:8080
```
浏览器打开 `http://localhost:8080`，首页会自动生成一本（链接带 `?b=xxxx`），直接开始用，无需密码。
本仓库已预置一本示例：`http://localhost:8080/?b=haohao0901`（标题「学霸小雨点的作业本」，含 9/1 当日作业）。

> 图片上传、OCR 识别需在服务器地址下运行（直接双击 `index.html` 打开 file:// 无法上传）。

### 把云端本子迁回本地
1. 从云端本子导出：用浏览器打开云端链接 `…/?b=你的ID`，开发者工具→Network 里找到 `GET /api/board/你的ID` 的响应，复制 JSON；
   或让我直接帮你 `curl` 云端接口把 JSON 存到 `data/boards/你的ID.json`。
2. 把该 JSON 存入本项目的 `data/boards/你的ID.json`。
3. 本地起服务后打开 `http://localhost:8080/?b=你的ID` 即可，数据全部在你本机，不再经过任何云服务器。

### 本地使用的取舍
- ✅ 数据 100% 在你电脑的 `data/` 目录，断网也能看（OCR 识别需联网下载语言包）。
- ⚠️ 跨设备同步：同一台电脑/同一局域网内多设备可共用（手机连同一 WiFi 访问 `http://你电脑内网IP:8080`）。
- ⚠️ 分享到 QQ 给外地家人：本地 `localhost` 外网访问不到。若想让外地家人也能看，要么继续用云链接，要么把本项目部署到任意公网 Node 主机（见下）。

## 部署到公网（Render，免费）
1. 把本项目推到你的 GitHub 仓库
2. 打开 https://render.com → New → Blueprint → 选择该仓库 → 用 `render.yaml`
3. 部署完成后得到 `https://xxx.onrender.com` —— 这就是可发 QQ 的公网地址
4. 打开首页会自动生成一本，把带 `?b=xxxx` 的链接发到 QQ 群即可

其他平台（Railway / Fly.io / 任意支持 Node 的 PaaS）同理：只需运行 `node server.js` 并暴露 `PORT`。

## 环境变量
| 变量 | 说明 | 默认 |
|------|------|------|
| `PORT` | 监听端口 | `8080`（部署平台自动注入） |

## 文件结构
- `index.html` —— 前端单文件应用（共享本读写、OCR、笔记、分享等）
- `server.js` —— 零依赖 Node 后端：静态托管 + 共享本读写 + 图片上传 + 健康检查
- `render.yaml` —— Render 一键部署配置
- `data/boards/` —— 各共享本 JSON 存盘目录
- `data/images/` —— 上传的笔记图片存盘目录

## 两点说明
- **图片识别用浏览器端 Tesseract.js**：首次识别需联网下载语言包（几 MB），手写体准确率有限，弹窗内可手动校对。
- **纯前端无法真正自动发 QQ 消息**：17:30 提醒为「页面常开时弹窗 + 一键转发」，非后台自动推送。
- **共享本无密码**：任何拿到链接的人都能看/改这本作业（家庭场景通常无所谓）。链接里的随机 ID 极难被外人猜中；若担心泄露，可改用带访问密码的版本。
