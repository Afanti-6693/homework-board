# 学霸小雨点的作业本（纯静态版）

给小学生用的「电子记作业本」网页：按科目标签分组作业、勾选圆圈打卡、粘贴微信群作业自动拆分、课堂笔记带图。

**纯前端实现**：不需要任何后端服务器、数据库，也不需要付费/绑卡。整个项目只有一个核心文件 `index.html`。

## 三种用法，挑最省事的

### 用法一：双击就能用（零部署，最快）

把 `index.html` 下载到电脑/手机，**双击用浏览器打开**即可。因为是纯静态网页，不联网也能用。

### 用法二：放到 GitHub Pages（得一个能发给家人的链接）

你的仓库是公开的，两步搞定：

1. 打开仓库 `https://github.com/Afanti-6693/homework-board`
   → 点 **Add file** → **Upload files**
   → 把新的 `index.html` **拖进去** → 底部 **Commit changes**
2. 仓库页 → **Settings** → 左侧 **Pages**
   → **Source** 选 **Deploy from a branch**
   → **Branch** 选 `main`、目录选 `/ (root)` → **Save**

等约 1 分钟，链接就是：

```
https://afanti-6693.github.io/homework-board/?b=haohao0901
```

国内浏览器、手机、QQ 里都能直接点开。

### 用法三：本地起服务预览

```bash
cd 本目录
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/?b=haohao0901
```

## 数据是怎么存的（重要）

| 场景 | 行为 |
|------|------|
| 自己用 | 作业存在**本机浏览器**，刷新、关机重开都不丢 |
| 发给家人 | 点「🔗 复制链接」，**整本作业被编码进链接**；对方打开即看到一模一样的内容 |
| 对方改完 | 对方再点「复制链接」回传给你，如此往复同步 |
| 笔记图片 | 图片**只留在本机**，不会塞进链接（否则链接会长到发不出去） |

> 这是纯前端方案的取舍：不需要服务器，但同步靠"链接传数据"而不是实时云端。
> 好处是零成本、零运维、永不过期；家人之间靠发链接同步一份快照，对记作业这个场景够用。

## 功能说明

- **标题**：点顶部标题即可改成自家孩子的名字
- **加作业**：选科目标签（如 📖语文）→ 写一条，或**粘贴微信群作业**（自动拆成多条）
- **打卡**：点圆圈勾选，全部完成有庆祝撒花动画
- **分享**：「🔗 复制链接」发 QQ/微信；「🐧 分享到 QQ」直接调起 QQ
- **笔记**：写课堂重点、粘贴/上传板书照片
  - 照片会自动压缩到最长边 1280px（7MB 手机原图 → 约 630KB），避免撑爆浏览器存储

## 内置示例

`?b=haohao0901` 首次打开自带一份示例作业（语文 2 条、数学 2 条、老师通知 2 条），可直接照着改。
换别的 `?b=任意ID` 就是一本全新的空白本。
